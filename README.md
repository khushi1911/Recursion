# Recursion in Java

This repository contains **basic to advanced recursion problems** implemented in Java.

## Topics Covered

* Basic Recursion
* Factorial
* Fibonacci Series
* Power Calculation
* Array Problems
* String Problems
* Backtracking
* Other Recursion Problems

## Technologies Used

* Java

## How to Run

1. Clone the repository.
2. Open the required `.java` file.
3. Compile and run the program.

```bash
javac filename.java
java filename
```

## Purpose

This repository was created to practice **recursion, problem-solving, and algorithmic thinking in Java**.
